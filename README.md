# Site Allan Besteiro

Site institucional do vereador Allan Besteiro, de Marituba, Pará. O projeto apresenta a identidade visual do mandato, informações institucionais, projetos e ações documentadas, trajetória, galeria e canais de contato.

## Tecnologias

- React 18.3.1
- Vite 6
- React Router DOM 6
- Lucide React
- JavaScript com módulos ES
- CSS com tokens visuais centralizados

## Pré-requisitos

- Node.js em versão compatível com as versões atuais do Vite e do React.
- npm.

## Instalação

Na raiz do projeto, instale as dependências:

```bash
npm install
```

## Desenvolvimento local

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

O Vite exibirá no terminal o endereço local para acesso no navegador.

## Build de produção

Gere os arquivos otimizados para produção:

```bash
npm run build
```

## Visualização do build

Depois de gerar o build, visualize a versão de produção localmente:

```bash
npm run preview
```

## Estrutura de pastas

```text
.
├── index.html
├── package.json
├── package-lock.json
├── vite.config.js
└── src/
    ├── App.jsx
    ├── main.jsx
    ├── data/
    │   ├── projects.js
    │   └── gallery.js
    └── styles/
        ├── global.css
        └── tokens.css
```

`src/App.jsx` reúne as páginas e componentes atuais. Os dados locais de projetos e galeria ficam em `src/data/`, enquanto a identidade visual e os estilos responsivos ficam em `src/styles/`.

## Estado dos conteúdos

O projeto ainda utiliza placeholders para fotografias, imagens de projetos e registros da galeria. O logotipo oficial, as informações biográficas, os dados de contato, os links de Instagram e WhatsApp e as fontes oficiais dos projetos aguardam confirmação ou recebimento. Nenhum projeto, obra, resultado, data, localidade ou dado institucional não confirmado deve ser tratado como informação publicada.
